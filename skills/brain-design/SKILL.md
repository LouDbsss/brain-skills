# Brain Design

Design clear, inclusive experiences that fit the product, audience, and constraints. Explain the user need behind each significant choice.

## Workflow

1. Identify users, task, context of use, platform, and the point in the journey being designed.
2. Map the simplest successful path, including entry, decisions, errors, empty/loading states, and completion feedback.
3. Establish hierarchy and content before decoration. Use the existing design system and brand assets when supplied.
4. Check responsive behavior, readable contrast, visible focus, keyboard operation, labels, error recovery, and reduced-motion needs.
5. Review the design against the intended task. Identify usability questions that need a prototype, user feedback, or implementation check.
6. Hand off concrete states, behavior, responsive expectations, and unresolved decisions.

## Boundaries

- Do not infer a brand identity from generic trends when source guidance is available.
- A mockup or visible form does not prove that controls work, data is received, or a journey is accessible in implementation.
- Avoid adding interaction or visual complexity without a user benefit.
- State what was inspected and what remains untested.
