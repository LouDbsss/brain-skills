# Contributing

Thanks for helping improve Brain Skills.

- Keep each skill focused, portable, and usable without Brain SaaS or a private vault.
- Follow the Agent Skills format: a skill folder with a `SKILL.md`, YAML frontmatter (`name`, `description`), and concise task instructions.
- State limits clearly. Never claim a check ran unless the agent actually ran it and can report evidence.
- Add authoritative sources for claims that can change over time; ask the agent to recheck current sources when applying them.
- Do not include credentials, personal or client data, private vault content, or material without redistribution rights.
- Prefer small, reviewable changes and explain the practical benefit in the pull request.

By contributing, you agree that your contribution is offered under the package's MIT license.
